# Schofy Website

This folder contains a standalone website for Schofy product information and public release downloads.

## Open locally

Open `index.html` in a browser.

## Release downloads

Public downloads:

- Standard: `../Version released/02 Standard Release/Schofy Setup 1.1.0.exe`
- Lite: `../Version released/03 Lite Release/Schofy Lite-1.1.0-x64.exe`
- Windows 7: `../Version released/04 Windows 7 Release/Schofy-Setup-1.1.0-win7.exe`

Unlimited and private school builds are supplied manually by Schofy support after confirmation.

## Assets

The website uses copied public app assets in `assets/` so it can be published separately from the app.
